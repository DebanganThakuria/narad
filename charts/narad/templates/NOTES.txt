Root admin password:
  The root user is "admin", with the password in the "{{ .Values.security.adminPasswordKey }}" key of the Secret {{ $secretName }}.
  Without that key, the node that created it generated one and wrote it to /var/lib/narad/admin-password
  on its own volume; it is never logged. Find that node with:
    kubectl logs -n {{ .Release.Namespace }} <pod> | grep 'seeded root admin with a generated password'
  then read the file, change the password and delete the file (docs/operate/users.md).
